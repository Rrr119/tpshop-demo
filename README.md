# tpshop-demo
TPshop电商商城实训项目
## 项目介绍
基于ThinkPHP框架开发的B2C电商商城实训项目。
实现商品浏览、商品检索、购物车、用户注册登录、订单提交、后台商品与订单管理等功能。
在线演示访问地址：<http://hmshop-test.itheima.net/index.php/Home/Goods/goodsList/id/31.html>

## 技术栈
- 后端：PHP + ThinkPHP
- 前端：HTML / CSS / JavaScript
- 部署环境：PHPStudy(Apache + MySQL)

##  项目主要功能
### 用户前台
- 用户注册、登录、退出
- 商品分类浏览、商品详情查看
- 商品加入购物车、购物车管理
- 提交订单

### 管理后台
- 商品上架、编辑、删除管理
- 用户会员管理
- 订单查看与管理
